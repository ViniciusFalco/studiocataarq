# Studio Catá Arquitetura

Site institucional e portfólio do Studio Catá Arquitetura, migrado para React, Vite e Tailwind CSS.

## Tecnologias

- React
- Vite
- Tailwind CSS

## Scripts

```bash
npm install
npm run dev
npm run build
npm run preview
```

## Estrutura

```txt
src/
├─ components/
├─ data/
├─ pages/
├─ utils/
├─ App.jsx
├─ main.jsx
└─ index.css

public/
├─ font/
└─ img/
```

## Rotas

- `/`
- `/projetos`
- `/obras`
- `/sobre`
- `/contato`
- `/projetos/:slug`

As URLs antigas com `.html` ainda são normalizadas internamente para as novas rotas React.
